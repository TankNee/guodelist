# Guodelist 设计系统

Superlist 的视觉语言 + impeccable 的质量底线。所有数值都落在 `src/index.css` 的 CSS 变量里，组件不写死颜色。

## 1. 色彩

| 令牌 | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--app` | `#ebe8e3` | `#121110` | 窗口画布（侧栏底色） |
| `--panel` | `#fffefc` | `#1a1917` | 列表面板 / 详情面板 |
| `--panel-2` | `#f5f3ef` | `#211f1d` | 分段控件槽、详情头部 |
| `--line` | `#e7e2da` | `#2b2825` | 分隔线、描边 |
| `--line-strong` | `#d9d3c9` | `#3a3632` | 未设置的属性 chip 虚线框 |
| `--ink` | `#1c1a17` | `#f2efe9` | 主文字 |
| `--ink-2` | `#5f5a52` | `#b3aca2` | 次要文字、备注 |
| `--ink-3` | `#6d655b` | `#9a938a` | 元信息（清单名、日期、计数） |
| `--brand` | `#e1543a` | `#f2694c` | 强调色：选中条、勾选、今天 |
| `--brand-ink` | `#b83b25` | `#ff9078` | 强调色的**文字**版本（保证 4.5:1） |
| `--brand-tint` | `#fbeae5` | `#2e1c17` | 极浅强调底 |

规则：

- 强调色是**信号**，不是装饰。只出现在：左侧选中条（2px）、勾选框、今天/过期的日期文字、快速新建的日期预览。
- 正文/占位符对比度 ≥ 4.5:1；大字号（≥ 24px）≥ 3:1。
- 优先级四档：低 `#4f7259`、中 `#8a5f14`、高 `#a8411f`、紧急 `#a82a1a`，都按 12px 文字在面板上的对比度挑过。

## 2. 字体

```
"Instrument Sans Variable", "PingFang SC", "Hiragino Sans GB",
"Microsoft YaHei UI", "Noto Sans SC", system-ui, sans-serif
```

- 拉丁用 Instrument Sans（避免 Inter 的「AI 默认感」），中文回退到系统黑体。
- 字号阶梯：34（页面标题）/ 21（任务标题）/ 15（列表任务）/ 13.5（正文）/ 12（元信息）/ 11（分组标签）。
- 字距：标题 `-0.038em`（不低于 -0.04em），正文 `-0.006em`。
- 数字用 `font-variant-numeric: tabular-nums`（`.num`）。

## 3. 间距与形状

- 面板圆角 16px，行/控件圆角 9–11px，chip 与按钮用全圆角。
- 面板内边距：左右 36px（`px-9`），顶部 28px；行内边距 12px × 9px。
- 行高：单行任务约 44–48px；分组之间 24px。
- 阴影只有两级：`.panel-shadow`（面板）与 `.pop-shadow`（浮层），都带偏移和柔和模糊，不用零偏移光晕。

## 4. 组件规则

| 组件 | 规则 |
|---|---|
| 任务勾选 | 17px 圆环，未选中 1.5px `--line-strong`；选中填充 `--brand` + 白色对勾（200ms 缩放淡入） |
| 任务行 | hover 浅灰底；选中 `#f0ece5` + 右缘 2px 强调条；标题完成态删除线 + `--ink-3` |
| 属性 chip | 已设置：实线描边 + `--panel` 底；未设置：虚线描边 + `--ink-3`；今天/过期使用强调底 |
| 侧边栏项 | 高 32px，圆角 9px；选中态 `--sidebar-accent` + 左缘 2px 强调条 |
| 分段控件 | 胶囊槽 `--panel-2`，选中项白底 + 1px 阴影 |
| 命令面板 | 560px 宽，距顶 16%，遮罩 `black/15` + 2px 模糊 |

## 5. 动效

只有两个编排过的时刻：

1. 详情面板进入：`translateX(10px) → 0` + 淡入，240ms，`cubic-bezier(.16,1,.3,1)`。
2. 勾选：对勾缩放淡入 200ms，圆环颜色/底色同步过渡。

其余交互一律 120–160ms 的颜色/背景过渡，不做逐项入场动画。

## 6. 无障碍

- 所有图标按钮带 `aria-label`；勾选是 `role="checkbox"` + `aria-checked`。
- 焦点环：2px `brand/55`，offset 2px。
- 标题层级 h1 → h2（详情内的小节），不跳级。
- 文本选中色、滚动条、光标都按令牌着色。

## 7. 窗口边框（平台规范）

窗框不画统一的“装饰性标题栏”，而是跟随平台：

- **Windows**：右上角三个 46×32 的按钮，最小化 / 最大化（还原图标随状态切换）/ 关闭；hover 为 `black/6`，关闭 hover 为 `#c42b1c` + 白图标；双击拖拽区切换最大化。
- **macOS**：左上角 12px 交通灯，间距 8px，hover 显示符号。
- 标题栏高 32px，整条是拖拽区，按钮加 `.no-drag`。
- 左侧固定品牌位：18px 应用图标（圆角 5px）+ 12.5px「Guodelist」，macOS 放在交通灯右边；侧边栏不再重复放 wordmark。

## 8. 设置面板

560px 宽对话框，分四段：外观、布局、数据、关于。

- 主题是三个等宽卡片（浅色 / 深色 / 跟随系统），选中态 `brand` 描边 + `brand/5` 底。
- 字号是胶囊分段：90 / 100 / 110 / 120%，作用于整个窗口的缩放。
- 布局段显示当前两栏宽度，提供「恢复默认」；与分隔线双击行为一致。
- 数据段导出 JSON、重置演示数据；破坏性操作用 `destructive` 文字色。

## 9. 日历

- 月视图：7 列 × 6 行，周一开头；格子最小高度随窗口伸缩，行间 `line/60` 分隔。
- 今天：日期数字填 `brand` 圆形，格子 `brand/3.5` 淡底；非本月日期降到 `ink-3/60`。
- 任务条：11.5px，前置清单 emoji，最多 3 条 + `+N`；完成态删除线。
- 周视图：7 列卡片，今天整列 `brand/30` 描边 + `brand/4` 底。
- 顶部：月份标题 28px，右侧「‹ 今天 › 月/周」；点日期跳当天列表。

## 10. 笔记编辑器

- Tiptap 3 + `tiptap-markdown`，存 Markdown 字符串。
- 正文 13.5px / 1.7 行高，颜色 `ink-2`；标题、列表、引用、代码块按 `.rich-text` 规则收敛到界面字号，不引入第二套排版。
- 三种状态，别让人误以为「被选中」：
  - 空闲：完全透明、无描边；
  - 悬停：只有 2% 的底色（`black/2`、暗色 `white/2.5`），不加边框；
  - 聚焦：3% 底色 + 1px `line/70` 描边，工具条淡入。
- 内边距：容器左右各 8px（配合 `-mx-2` 抵消），正文与「备注」标签保持同一左边缘；上下 6px。
- 工具条只在聚焦时出现（24px 高、13.5px 图标），不抢正文注意力。
- 待办列表用 13px 原生 checkbox，强调色 `brand`。
- 行内代码 / 代码块使用等宽字体，仅在代码场景出现。

## 11. 桌面日历（横屏画板）

- 默认 1600×900（按显示器 90% 计算），可缩放；`alwaysOnBottom`，`skipTaskbar`，不抢焦点。
- 尺寸菜单三档：紧凑（约 66% 屏宽）/ 标准 / 铺满（整屏，1920×1080 这类），都由 Rust 端改窗口尺寸并居中，不是打开主窗口。
- 外层 8px 透明边距，卡片 22px 圆角 + `panel/95` + 背景模糊；阴影朝下偏移。
- 头部：左侧固定 292px 宽标题（避免「月 / 周 / 日」切换时整排按钮左右跳），紧跟 3×40px 的分段控件（选中胶囊用 `translateX` 200ms 平滑滑动）；右侧上一页 / 今天 / 下一页 / 尺寸菜单 / 锁定 / 打开主窗口 / 隐藏。
- 背景透明度可调（30%–100%），默认 80%；浅色 `rgba(255,254,252,a)`、深色 `rgba(11,11,13,a)`，直接叠在壁纸上。
- 画板每次获得焦点都会调用 `widget_sink` 重新 `set_always_on_bottom`，保证主窗口永远在它上方。
- **月视图**：7×6 网格，单元格等分；今天 `brand` 实心数字，选中日 `brand/7` 底色；格内最多 4 条任务，超出 `+N`；悬停右上角出现 `+`。右侧 330px 为当天清单。
- **周视图**（参考苹果日历）：左侧 56px 小时槽（24 小时 × 44px），顶部「全天」行放无时间的任务；有时间的任务按 `dueTime`–`endTime` 画成高度=时长的色块（最短 24px），重叠任务自动分栏；今天整列 `brand/3.5` 底 + 顶部红点的时间线；双击空白时段把该小时填进底部添加框。
- **任务颜色**：按清单哈希到 8 色**粉彩**调色板（玫瑰 / 蜜桃 / 奶油 / 薄荷 / 天蓝 / 薰衣草 / 青 / 沙），块用实色粉彩填充 + 同色深阶文字（暗色主题换成深底 + 亮字），1px 20% 同色描边；不用左侧色条。30 分钟以内的块自动切成单行「10:00 标题」。
- 时间段编辑在详情里：开始 / 结束两个 `time` 输入 + 30 分钟 / 1 小时 / 2 小时快捷键；没有结束时间时按 1 小时渲染。
- **日视图**：按时间排序的议程（左列显示 `HH:mm` 或「全天」），最宽 1040px 居中。
- **详情弹窗**：520px，标题 + 属性 chips + 富文本备注 + 子任务 + 删除；改动即时写回 store。
- **锁定**：头部锁图标切换只读，勾选/添加/删除/编辑全部禁用，只保留查看；状态持久化在 `settings.widgetLocked`。
- 与主窗口共享 localStorage，靠 `storage` 事件触发 rehydrate。

## 12. 主题系统

两套「主题包」，和明暗模式正交（`settings.themePack` + `settings.theme`，写在 `<html data-pack>` 上）：

| | 经典 classic | 星星人 starry |
|---|---|---|
| 画布 | `#EBE8E3` 暖灰 | `#FFF5E6` 奶油 |
| 面板 | `#FFFEFC` | `#FFFDF7` |
| 强调 | `#E1543A` 朱红 | `#F2915F` 蜜橘 |
| 事件色 | macOS 粉彩 8 色 | 糖果粉彩 8 色（更暖、更甜） |
| 装饰 | 无 | 云朵渐变（粉/黄/蓝/薄荷）+ 星星人 SVG |

- 星星人是**原创 SVG**（五角星 + 眼睛 + 腮红），出现在标题栏、日历标题、右侧栏标签、桌面画板角落；不复制任何第三方插画。
- 事件色板由 `eventColor(listId, theme, pack)` 决定，换主题包时日历块、全天条、月份格同步换色。
- 日期选择器是自绘 `DatePicker`（不使用 `input[type=date]` 的原生弹层），保证和主题一致；日期、开始/结束时间都在同一个弹层里。
